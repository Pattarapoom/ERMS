# 🏥 ERMS — Emergency Room Management System

ระบบจัดการตารางเวรพยาบาลอัจฉริยะ ออกแบบมาเพื่อลดภาระงานของหัวหน้าเวร และบริหารจัดการกำลังพลในแผนกฉุกเฉินอย่างมีประสิทธิภาพ

## ✨ คุณสมบัติเด่น (Features)
- **📅 ระบบจัดตารางเวรรายเดือน**: จัดตารางอัตโนมัติภายใต้เงื่อนไขวิชาชีพพยาบาล (M/A/N)
- **🌓 การเชื่อมต่อรอยต่อเดือน**: ตรวจสอบลำดับเวรข้ามเดือนอัตโนมัติ (เช่น ห้าม N ต่อ M ข้ามเดือน)
- **📑 จัดการคำขอ (Requests)**: ระบบแจ้งลา และสลับเวร พร้อมกระบวนการอนุมัติ
- **📊 สถิติแบบ Dashboard**: สรุปภาระงานและวันลาแยกตามประเภทและรายเดือนอย่างละเอียด
- **📥 Import/Export**: รองรับการส่งออกข้อมูล และนำเข้าข้อมูลกลับมาแสดงผลผ่าน CSV
- **🎨 Modern UX/UI**: ดีไซน์ทันสมัย รองรับ Dark Mode (Teal Theme) และใช้งานง่าย
- **📱 Responsive Design**: ใช้งานได้ดีทั้งบนคอมพิวเตอร์และแท็บเล็ต

## 🚀 วิธีการเข้าใช้งาน (Quick Start)
ระบบนี้เป็น **Static Web Application** ที่ทำงานบนเบราว์เซอร์ 100% ไม่ต้องติดตั้ง Database:
1. ดาวน์โหลดหรือ Clone โฟลเดอร์นี้ลงในเครื่อง
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (แนะนำ Chrome หรือ Edge)
3. เริ่มต้นใช้งานได้ทันที!

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)
- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **Storage**: Browser LocalStorage (ข้อมูลจะถูกเก็บไว้ที่เครื่องของผู้ใช้)
- **Icons**: Google Material Symbols

## 📋 ข้อแนะนำการใช้งาน
1. **การบันทึกข้อมูล**: ข้อมูลจะถูกเก็บไว้ที่เครื่องเบราว์เซอร์ที่ใช้จัดตาราง แนะนำให้ผู้ดูแลระบบ (Admin) ทำการ **Export CSV** เก็บไว้เป็นระยะเพื่อสำรองข้อมูล
2. **การใช้งานร่วมกัน**: สำหรับการใช้งานในหน่วยงาน หากต้องการให้พยาบาลเห็นตารางล่าสุด ผู้ดูแลระบบสามารถ Export CSV แล้วส่งให้พยาบาลนำเข้า (Import) ในเครื่องของตนเองได้
